# Data Notes

## Raw files
- `Charetteetal2024_CJFAS_Fish.csv`: fish-level observations (individual fish metrics).
- `Charetteetal2024_CJFAS_Baselines_DOC.csv`: lake-level baseline chemistry values.

## Derived file
- `analysis_df.csv`: cleaned and joined analysis-ready dataset generated by `analysis/00_build_project_outputs.R`.

## Missing value handling
- Input missing values interpreted as: `""`, `"NA"`, and `"-999"`.
- Rows are not globally dropped. Missing values are filtered per analysis/plot as needed.

## Key analysis variables
- Explanatory: `doc_mgl`
- Responses: `pelagic_diet_proportion`, `trophic_position`, `length_mm`
- Grouping: `fish_species`, `lake`, `region`
- Support: `d13c`, `d15n`, `c_n`
